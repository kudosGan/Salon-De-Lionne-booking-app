# Salon image assets

Drop your images into these folders using EXACTLY these file names
(or edit lib/core/config/salon_assets.dart to match your names).

| Folder                     | File                | Used for                                  |
|----------------------------|---------------------|-------------------------------------------|
| assets/images/logo/        | logo.png            | Salon logo (transparent PNG is best)      |
| assets/images/backgrounds/ | landing_bg.jpg      | Landing page hero background              |
| assets/images/strip/       | bottom_strip.jpg    | Continuously scrolling strip at page end  |
| assets/images/hairstyles/  | (your styles)       | Hairstyle catalogue (Stage 2)             |
| assets/images/gallery/     | gallery_1.jpg ...   | Landing page gallery                      |
| assets/images/salon/       | about.jpg           | "About the salon" photo                   |
| assets/images/icons/       | (optional)          | Custom icons                              |

Until a file exists the app shows a soft branded placeholder, so nothing breaks.
